## Review Checklist

### Requirements Coverage

- [ ] All scenarios from slice plan are represented in the design
- [ ] Entry point matches slice plan
- [ ] Observable outcome is achievable from the design

### Accessibility (UI only)

- [ ] Colour contrast meets WCAG 2.2 AA (4.5:1 for text, 3:1 for large text)
- [ ] Interactive elements are keyboard accessible
- [ ] Focus order is logical
- [ ] Form inputs have visible labels
- [ ] Error states are clearly communicated

### Design System Fidelity (UI only)

- [ ] Uses only colours from the design system
- [ ] Uses only fonts from the design system
- [ ] Spacing follows the defined scale
- [ ] Component patterns match the design system

### API/MCP Contract (if applicable)

- [ ] All endpoints/tools are documented
- [ ] Request/response schemas are complete
- [ ] Error responses are defined
- [ ] Authentication requirements are specified
